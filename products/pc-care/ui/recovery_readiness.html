PC CARE 안전 복구 준비 카드

Windows가 불안정하거나 부팅되지 않을 때 무엇부터 확인할지 정리하는 오프라인 안내서입니다.

기기 상태를 읽거나 검사하지 않으며, 체크 상태는 저장·전송되지 않습니다. 체크 표시만으로 복구를 승인하지 않습니다.

중요: 현재 기능은 확인 및 상담 준비까지만

파일 복사·복원·시스템 수리·BitLocker 잠금 해제·파티션 수정은 이 화면에서 전혀 실행되지 않습니다.

WinRE 파일 복사 기능은 Release B 미승인. USB 프로그램 자체는 부팅용 Windows 복구 미디어가 아닙니다. 데이터 손실 위험이 있으면 계속 재시도하지 말고 전문 복구를 우선 검토하세요.

1. 현재 PC 상태에 따른 우선 행동

  • Windows가 정상 부팅: 중요 파일을 다른 물리 장치에 별도 보관하고, 승인되지 않은 자동 수리 대신 읽기 전용 건강검진 결과를 확인합니다.
  • Windows가 간헐적으로 부팅: 저장장치 이상 신호가 있으면 추가 쓰기·강제 재부팅·장시간 검사를 피하고 데이터 보호를 먼저 검토합니다.
  • Windows가 전혀 부팅되지 않음: Microsoft 정식 Windows 복구 환경(WinRE) 진입을 수동으로 준비합니다. AXMART의 WinRE 기능은 현재 읽기 전용 상태 확인만 지원합니다.
  • BitLocker 잠금·장치 식별 불가: 프로그램이 키를 요청·저장·우회하지 않습니다. 소유자가 Microsoft 공식 복구 절차로 확인해야 하며, 자동 복사는 차단합니다.

2. 복사·수리 전에 수동으로 확인할 조건

자가 확인표 · 체크해도 프로그램은 아무 작업을 하지 않음

위 조건은 현재 자동으로 확인되지 않았습니다. 하나라도 불명확하면 복사·수리는 보류합니다. 드라이브 문자가 다르다고 다른 물리 장치인 것은 아닙니다.

3. 수리점·전문가에게 전달할 질문

  1. 관찰한 증상과 Windows 이벤트/저장장치 상태의 근거 수준은 무엇인가요?
  2. 데이터를 먼저 보호하려면 어떤 조치가 가장 안전하며, 확인하지 못한 항목은 무엇인가요?
  3. 부품 교체 또는 운영체제 복구 전에 확인할 대안·비용·추가 테스트는 무엇인가요?
  4. 백업 성공을 어떻게 검증하고, 실패하거나 일부만 복사된 경우 어떻게 처리하나요?

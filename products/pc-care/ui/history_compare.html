반복 검사 결과 비교

같은 PC에서 생성한 읽기 전용 진단 JSON 두 개를 사용자가 직접 선택합니다. 파일은 이 브라우저의 메모리에서만 처리하며 서버로 보내거나 보관하지 않습니다.

여러 검사 이력 한 번에 선택

사용자가 직접 선택한 JSON만 읽습니다. 파일당 2MB, 최대 25개·합계 12MB. 파일 이름·경로는 화면에 표시하지 않습니다.

검사 JSON 두 개 이상을 직접 선택하면 날짜순 목록이 나타납니다.

이력 자동 검색·영구 저장·삭제 기능은 없습니다. 아래 기존 개별 선택도 계속 사용할 수 있습니다.

로컬 JSON 두 개 선택

파일당 최대 2MB · 다른 PC의 기록은 비교하지 마세요. 인쇄 버튼은 유효한 비교 이후에만 활성화됩니다.

비교 결과

파일을 선택한 후 비교 버튼을 누르세요.

오프라인 수리 상담 초안

선택한 점검 JSON을 검토하고 인쇄할 수 있습니다. 원본 데이터는 외부에 전송되지 않으며, 원인 확정이나 수리 승인으로 사용하지 않습니다. 로컬 상담 초안 화면 열기

개인정보·안전

선택한 JSON에는 기기 정보가 있을 수 있습니다. 비교 화면은 안전한 경고 코드와 요약 통계만 표시합니다. 별도의 계정·서버·외부 통신이 없습니다.

과거 보고서를 지우려면 Windows 파일 탐색기에서 해당 파일을 직접 확인하여 삭제하세요. 이 도구는 파일을 수정하거나 삭제하지 않습니다.

경고가 최신 보고서에서 보이지 않는 것은 고장 해결의 증거가 아닙니다. 저장장치와 PC 동일성도 이 기능으로 확인할 수 없습니다.

# 블루스크린/부팅 장애 분기 가이드 (v0.1)

제품의 자동 진단은 **실제로 확인 가능한 증거만** 사용한다. 특정 파일이나 이벤트 하나로 원인을 확정하지 않는다.

| 증상/증거 | 의미 | 안전한 다음 단계 | 현재 자동 수리 |
|---|---|---|---|
| Windows 부팅 가능, 이벤트 1001 + `BugCheck`/`WER-SystemErrorReporting` | 최근 Windows 블루스크린 기록 | STOP 코드·최근 변경·업데이트 점검, 장치 진단 | 시스템 파일 복구만 승인형 |
| 이벤트 41/6008, 1001 없음 | 예기치 않은 종료, 정전·강제 종료·프리징 등 가능 | 전원, 온도, 메모리/드라이버 추가 진단 | 없음 |
| 디스크 건강 Warning/Unhealthy 또는 관련 저장장치 오류 이벤트 | 저장장치 고장 가능성 (확증 아님) | **데이터 백업/복구 우선, 쓰기 복구 금지** | 차단 |
| Windows 부팅 불가 + WinRE에서 Windows 설치 볼륨 발견 | Windows 폴더가 접근 가능, 원인 미확정 | Microsoft **시동 복구(Startup Repair)** 안내 | 자체 수리 없음 |
| WinRE에서 MEMORY.DMP/Minidump 파일 발견 | 과거 블루스크린 덤프 흔적 가능 | 별도 덤프 분석 필요 | 없음 |
| WinRE에서 SrtTrail.txt 발견 | 과거 시동 복구 로그 존재 | 파일 내용 전문가 해석 | 없음 |
| BitLocker 볼륨 잠김 | 파일 접근 제한 | 정당한 소유자가 Microsoft 안내에 따라 복구 키 확보 | 키 우회/자동 해제 없음 |
| Windows 설치 볼륨을 찾지 못함 | BitLocker 잠금·저장소 드라이버 문제·물리 고장 등 가능 | 복구 전문 지원 | 없음 |

**데이터 보호 원칙:** 물리 장애 의심 시 CHKDSK `/r`나 파티션 복구를 자동 실행하지 않는다. 손상된 디스크에 쓰기가 발생하면 복구 가능성이 낮아질 수 있다.

**Windows 복구 환경:** USB에 자체 Windows PE는 동봉하지 않는다. 사용자가 Microsoft 정식 복구/설치 USB를 준비해야 한다. 

**수리 승인은 증상 확인 및 백업 이후에만:** `RUN_SAFE_REPAIR.cmd`는 관리자 + `BACKUP` + `REPAIR`를 요구하고 DISM /RestoreHealth 다음 SFC /scannow만 실행한다. 수리가 실패할 수 있으며 로그와 종료 코드를 저장한다.

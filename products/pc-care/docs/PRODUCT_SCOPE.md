# 상품 설계안 — AXMART PC CARE USB (가칭)

- 사용자 가치: 컴퓨터가 정상 동작할 때 한 번씩 실행해 위험 신호를 찾고, 고장/블루스크린 발생 시 원인 판별을 지원하며, 안전하게 가능한 Windows 시스템 복구를 단계적으로 지원.
- 대상: Windows 10/11 x64 개인 사용자, Windows 관리자가 아닌 초보자도 이해하는 한국어 HTML 결과.
- 범위 v0.1: USB에 복사해 사용 가능한 읽기 전용 PowerShell 진단기 + 명시적 백업/승인 후 Windows 시스템 파일 복구 + WinRE 읽기 전용 진단 배치.
- 제외 v0.1: USB 자체 부팅, 오프라인 완전 자동 복구, 디스크 파티션/EFI 자동 변경, BIOS/UEFI 조작, 물리 부품 수리, 실시간 백신/AI 진단, 예약 실행, 결제/DRM.
- 차기: 실제 Windows 10/11 2대 이상, 관리자·일반 권한, 장치별 HDD/SSD, BitLocker(잠김/해제), 드라이버 충돌, 반복 BSOD, 부팅 실패 VM 테스트 → 장애 분류 정확도 검증.
- 5,000원 수익 구조: 일회성 ZIP 다운로드, 자동 서버 비용 0원 목표. 결제 수수료, 세금, 환불/고객지원 비용은 별도 고려. 고장 수리 보증 판매 문구 금지.
- 상태: 코드 초안과 Linux 기반 정적 테스트 수행 가능. Windows 실기기 검증 전 판매 불가.

# 안전 경계 — AXMART PC CARE v0.1-alpha

## 기본 정책

- `RUN_HEALTH_CHECK.cmd`: Windows 10/11에서 **읽기 전용** 진단. 시스템 파일·레지스트리·부트 설정을 바꾸지 않는다. 실행 결과 JSON 및 HTML은 실행 USB의 `REPORTS` 폴더 또는 사용자의 Documents 아래에 **로컬 저장**한다.
- `RUN_SAFE_REPAIR.cmd`: **별도 선택**. 관리자 권한 + 백업 완료 `BACKUP` 입력 + 변경 승인 `REPAIR` 입력을 모두 요구한다. Microsoft DISM `/RestoreHealth` 성공 후 SFC `/scannow`만 실행한다. Microsoft 프로그램 자체의 작업을 중간에 종료하지 않아야 한다. 이 두 명령은 실제 Windows 파일을 변경할 수 있다.
- `recovery/WINRE_READ_ONLY.cmd`: Windows 복구 환경 명령 프롬프트에서 **사용자가 직접 실행**하는 인벤토리 전용. 자동 부팅 USB가 아니며 부트로더나 파티션을 고치지 않는다.
- Windows 11/10을 직접 구동할 수 없거나 PowerShell/관리자 정책이 제한된 PC에서는 기능이 제한된다.

## 중요 제한

- 물리적 SSD/HDD 고장(이상 소음/SMART 경고 포함), 데이터가 중요한 컴퓨터: **복구 명령보다 원본 보존과 데이터 백업이 우선**. DISM/SFC를 포함해 무리한 복구를 권장하지 않는다.
- `chkdsk /f /r /x`, `bootrec`, `bcdboot`, `diskpart clean`, 재설치/초기화, 강제 재부팅은 **자동 실행하지 않는다**.
- 시스템 이벤트 41은 비정상 종료이지 블루스크린 확증이 아니다. 이벤트 1001의 BugCheck 관련 공급자 기록을 구별하여 표시한다.
- SMART/NVMe 데이터는 장치·드라이버마다 제공되지 않으며 '정상' 표시가 수명 보장을 의미하지 않는다.
- BitLocker 키 입력·저장·업로드·우회 기능은 제공하지 않는다. 외부 복구 USB를 수동 부팅하면 복구 키가 필요할 수 있다.
- USB 드라이브 자동 실행은 지원하지 않는다. 사용자가 신뢰할 수 있는 배포본인지 확인한 뒤 파일을 명시적으로 실행해야 한다.
- 시스템 로그는 민감할 수 있다. 보고서는 인터넷 전송하지 않지만 고객이 직접 공유할 때 민감 정보가 포함될 수 있는지 검토한다.

## 보안·배포

현재 PowerShell 파일은 코드 서명하지 않은 **시험용 원본**이다. `.cmd` 실행기는 `-ExecutionPolicy Bypass`를 해당 PowerShell 프로세스에만 적용한다. 기업 보안 정책이나 실행 제한을 우회하는 도구로 사용하지 않는다. **정식 판매 전 코드 서명·악성코드 오탐·권한/안티바이러스·Win11/Win10 실기기 테스트 필요.**

독립 부팅형 WinPE/Windows 이미지 또는 Microsoft 실행 파일을 동봉하지 않는다. 복구 미디어는 사용자가 Microsoft 정식 경로에서 별도로 만들도록 안내한다. 상용 재배포 가능 여부는 권리 검토 없이는 보장할 수 없다.
